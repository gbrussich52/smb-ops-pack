# smb-ops-desk (Front Desk Ops)

Skills, rules, and an agent that run the front desk for a solo local service business on the owner's **Gmail + Google Calendar**, with an optional one-sheet pipeline (`smb-ops-pipeline`).

- Skills: getting-started, inbox-triage, lead-follow-up, booking-coordinator, pipeline-keeper, review-desk, ops-safety
- Rules: no-unsolicited-send, draft-before-send (always on)
- Agent: front-desk-ops
- Auth: none in this plugin. It uses the Gmail and Google Calendar connectors you already have.
- Not for HIPAA covered entities or clinical PHI. No compliance claims.
